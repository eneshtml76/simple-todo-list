# Simple To-Do List

A simple to-do list web app built with HTML, CSS, and JavaScript. This was my first small project to practice front-end web development.

## Features

- Add new tasks
- Mark tasks as done (click on the task text)
- Delete tasks
- Add tasks by pressing Enter

## Technologies used

- HTML
- CSS
- JavaScript (vanilla, no frameworks)

## How to run

1. Clone or download this repository
2. Open `index.html` in your browser

That's it, no installation needed.

## File structure

```
simple-todo-list/
├── index.html   # page structure
├── style.css    # styling
└── script.js    # app logic
```
